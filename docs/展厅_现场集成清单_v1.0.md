## 1. 大屏机与浏览器矩阵

### 1.1 机器配置

| 档位 | CPU | 内存 | GPU | 存储 | 网络 | 用途 |

### 1.3 DPR 1.0 验证（必做）

代码里是 `renderer.setPixelRatio(Math.min(devicePixelRatio, 1.5))`，所以系统缩放 125%/150% 会悄悄把渲染分辨率放大到 3200×1800 / 3840×2160。

1. 系统显示设置：分辨率 2560×1440，缩放 **100%**。
2. Chrome 按 `Ctrl+0` 复位缩放，`F11` 全屏。
3. 地址栏打开 `https://192.168.30.95:18443/stage/?live=1&area=exhibit`，开发者工具 Console 粘贴：

```js
(() => {
  const c = document.querySelector('#scene');
  const g = c.getContext('webgl2') || c.getContext('webgl');
  const d = g && g.getExtension('WEBGL_debug_renderer_info');
  console.log(JSON.stringify({
    dpr: devicePixelRatio,
    screen: [screen.width, screen.height],
    inner: [innerWidth, innerHeight],
    canvas: [c.width, c.height],
    gpu: d ? g.getParameter(d.UNMASKED_RENDERER_WEBGL) : 'n/a'

})()
```

通过标准：`dpr === 1`，`screen === [2560,1440]`，`canvas === [2560,1440]`，`gpu` 含 `NVIDIA`（不是 `SwiftShader` / `llvmpipe`）。
不通过处理：先把系统缩放改回 100%；仍不对就查 `chrome://gpu` 的 WebGL2 是否为 Hardware accelerated。

### 1.4 2K 帧率验证（10 分钟）

在同一个 Console 粘贴，采样 10 秒：

```js
new Promise(r => {
  let n = 0, prev = performance.now(), t0 = prev, d = [];
  const f = () => {
    const now = performance.now(); d.push(now - prev); prev = now; n++;
    if (now - t0 < 10000) requestAnimationFrame(f);
    else {
      const s = [...d].sort((a, b) => a - b);
      console.log(JSON.stringify({
        frames: n,
        avg_fps: +(n / ((now - t0) / 1000)).toFixed(1),
        min_fps: +(1000 / Math.max(...d)).toFixed(1),
        p99_ms: +s[Math.floor(s.length * 0.99)].toFixed(1),
        over_33ms: d.filter(x => x > 33.4).length,
        over_100ms: d.filter(x => x > 100).length
      }));
    }
  };
  requestAnimationFrame(f);
})
```

通过标准（连续 10 分钟，每 10 秒采一次）：`avg_fps ≥ 55`、`min_fps ≥ 30`、`over_100ms === 0`。
数字人线基准：2560×1440 / DPR 1.0，603 秒平均 60 fps、最低 59、0 个 >33.4ms 卡顿帧。

## 2. 部署形态、端口与拓扑

### 2.1 形态：一体机，不拆独立服务机

理由（均为实测约束，不是偏好）：
- broker 只监听 `127.0.0.1:8787`，与网页同源代理 `/voice/*` 才通；拆机要多一跳且要改信任边界。
- WeKnora 是本地 Docker（`WeKnora-app` 等 5 个容器），依赖本机 Docker 网络与数据卷。
- d1-2B 是本地 `llama-server`，`127.0.0.1:18788`。
- 断网回放、证书、开机自启都绑在这一台上，拆开只会多一个故障点。

### 2.2 端口清单

| 端口 | 当前绑定 | 用途 | 对 LAN | 处置 |
|---|---|---|---|---|
| 18080 | 0.0.0.0 | HTTP 静态页 / 脚本预览 | 是 | 保留，仅预览 |
| 18443 | 0.0.0.0 | HTTPS 实时入口（麦克风必需安全上下文） | 是 | **现场唯一入口** |
| 8787 | 127.0.0.1 | broker（session/decide/rag） | 否 | 保持 |
| 18788 | 127.0.0.1 | d1-2B 本地动作模型 | 否 | 保持 |
| 8881 | 0.0.0.0 | WeKnora API | 是 | **改 127.0.0.1**（X5） |
| 8880 | 0.0.0.0 | WeKnora 管理 UI | 是 | **改 127.0.0.1**（X5） |
| 7897 | 127.0.0.1 | Clash 代理，GPT-Live 用 | 否 | 保持，做存活检查 |

改 X5 的位置：`/home/xiaokai/WeKnora/docker-compose.yml`
- 前端 `ports: "${FRONTEND_PORT:-80}:80"` → `"127.0.0.1:${FRONTEND_PORT:-80}:80"`
- 应用 `ports: "${APP_PORT:-8080}:8080"` → `"127.0.0.1:${APP_PORT:-8080}:8080"`
改完 `docker compose up -d weknora-frontend weknora-app`（以实际服务名为准），用 `ss -ltnp | grep -E '8880|8881'` 确认只剩 127.0.0.1。

## 3. 网络与断网切换

### 3.1 现场网络要求（三条同时满足）

1. 展厅局域网，固定 IP `192.168.30.95`（有线 `eno1`）。备用无线是 `192.168.32.45`，两 IP 都在证书 SAN 内，但**验收只认有线**。
2. 公网：TCP 443 出站 + UDP 443 出站（WebRTC），GPT-Live 经 Clash。
3. 到 `172.20.109.174:4000` 的内网路由（当前是 `tun1` VPN）。**这是 RAG 的命门**，没有它 RAG 静默降级为“无知识库”，不会报错，只会答得空泛。

### 3.2 单点与监控

| 单点 | 断了的表现 | 检查 | 处置 |
|---|---|---|---|
| Clash 7897 | 实时通话建不起来，按钮报错 | `curl -x 127.0.0.1:7897 ...` 失败 | 重启 Clash Verge；kiosk.sh 启动时已检查 |
| tun1 VPN | 普通问答正常，RAG 永远 miss | `ip route get 172.20.109.174` 不走 tun1；TCP 4000 不通 | 重连 VPN；未恢复则执行 §3.3 离线切换 |
| 公网 UDP | 能建会话但没声音/断续 | 真机通话听不到回答 | 改走 TCP/TURN；仍不行则离线切换 |

### 3.3 断网切换动作（P0）

**触发条件**（满足任一，值守立即切换，不等待）：
- 连续 2 次点“开始实时通话”都失败；
- `https://192.168.30.95:18443/stage/?live=1` 页面 30 秒内没有出字；
- 确认公网或 Clash 中断。

**执行人**：展厅运维（现场值守）。应用工程远程不参与，避免等待。

**动作（60 秒内完成）**：
1. 关闭当前 Chrome 窗口（`Alt+F4`）。
2. 双击桌面「离线预录」快捷方式，等价命令：
   `google-chrome --kiosk --user-data-dir=$HOME/.config/open-annie/kiosk-profile "http://192.168.30.95:18080/stage/?replay=demo/live/session.json&decisions=demo/live/decisions.json"`
3. 点击画面上的「Play the demo」一次，确认 Annie 开口、字幕滚动。
4. 在值守表记录切换时刻与原因。

**耗时**：熟练后 30 秒，首次演练 60 秒。**不验收**：断网自由对话。

**现状限制（必须写明）**：第 2 步回放的是仓库 97 秒 demo，内容不是展厅脚本。产品 D2 要的「迎宾 + 3 个讲解点 + 送别 + 不黑屏」在 `实时语音` 交付 `/offline` 路由与预录资产前**不成立**，验收表 D2 不能签字。

## 5. 每日开馆前 5 分钟（贴在现场）

1. 看大屏：应是 Annie 站立 idle，不是登录页、不是报错页。

5. 在值守表打勾并写时间。
